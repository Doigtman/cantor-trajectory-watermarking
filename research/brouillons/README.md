# Fourre-tout / Brouillons

Espace volontairement ouvert aux intuitions, fragments, analogies, pistes non vérifiées, objections et résultats abandonnés.

Chaque entrée devrait indiquer : date, origine, thème(s), statut, lien éventuel vers un article ou une expérience. Ne pas effacer les idées simplement parce qu'elles n'ont pas abouti. Les agents peuvent proposer une promotion vers une branche de recherche, mais la promotion doit être tracée.

Sous-dossiers suggérés : `idees/`, `notes/`, `questions/`, `impasses/`.
