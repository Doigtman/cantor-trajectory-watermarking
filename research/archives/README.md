# Archives de provenance

Conserver les documents originaux, leur date, leur nom, leur empreinte SHA-256 et leur origine. Les captures de l'interface GitHub sont des traces contextuelles, pas des figures scientifiques. L'enveloppe e-Soleau historique et les éventuels autres papiers pourront être classés ici comme archives, sans les substituer aux versions de travail.

Avant publication sur ce dépôt public, vérifier que les archives ne contiennent ni secrets opérationnels ni données personnelles de tiers.
